# Step-by-Step Integration Guide: AI QCM Generator (n8n + Gemini Pro + Laravel)

This guide is specifically written for **beginners**. It explains step-by-step how to configure n8n and your Google AI Pro account to automatically generate QCMs (quizzes) inside SoliQuiz.

---

## 📌 Step 1: Retrieve your Google AI Studio (Pro) API Key

1. Log in to **Google AI Studio**: [https://aistudio.google.com/](https://aistudio.google.com/) using your Google AI Pro account.
2. Click the blue **"Get API key"** button in the top-left corner.
3. Click **"Create API key"**.
4. Copy the long key displayed (it usually starts with `AIza...`). Save it somewhere safe; we will enter it into n8n shortly.

---

## 🔄 Step 2: Run n8n on your Computer

To start your local n8n server, open your terminal and run the following command:
```bash
npx n8n
```

Once n8n starts successfully:
1. Open your browser and go to: [http://localhost:5678](http://localhost:5678)
2. Log in or create a local account if required.

---

## 📐 Step 3: Configure the n8n Workflow

Your workflow should connect the nodes exactly like this:

```
[ Webhook (POST) ] ───► [ Basic LLM Chain ] ───► [ Respond to Webhook ]
                              │ (Model*)
                        [ Google Gemini Chat Model ]
```

Here is how to configure **each node** in detail:

### 1. "Webhook" Node (Trigger)
This node receives the request sent by Laravel.
* **How to add it**: Click the `+` button in n8n, search for **Webhook**, and add it.
* **Configuration**:
  * **HTTP Method**: Select `POST`.
  * **Path**: Enter `generate-qcm`.
  * **Respond**: Select `Using Respond to Webhook Node` (crucial so n8n waits for the AI to finish before responding to Laravel).

---

### 2. "Basic LLM Chain" Node (AI Orchestrator)
This node combines your prompt rules and the AI model.
* **How to add it**: Click the `+` button, search for **Basic LLM Chain**, and add it. Connect the output of the **Webhook** node to its input.
* **Configuration (Follow carefully)**:
  * **Source for Prompt (User Message)**: Change this from *Connected Chat Trigger Node* to **Define Below**. This is critical for the Laravel Webhook to work!
  * **Prompt (User Message)**: Enter exactly this:
    ```text
    Generate a QCM for the topic "{{ $json.body.topic }}" containing {{ $json.body.question_count }} questions. The type of questions must be: "{{ $json.body.question_type }}".
    ```
  * **Chat Messages (if Using a Chat Model)**: Click **Add Message**, choose the type **System**, and paste this strict instruction block into the Message field:
    ```text
    You are an expert pedagogical assistant. Generate a QCM quiz matching the exact specifications requested.
    
    The user's requested question type is either "single", "multiple", or "both".
    - If "single": Every generated question must have exactly one correct option (type "single").
    - If "multiple": Every generated question must have more than one correct option (type "multiple").
    - If "both": Generate a healthy mix of both single-choice and multiple-choice questions.
    
    You MUST return ONLY a raw, valid JSON object containing a "title" and a "questions" array. Do NOT wrap the JSON inside Markdown code blocks (do not put ```json or ``` at the beginning or end). Do not write introductory text or conversational feedback.
    
    Expected JSON Structure:
    {
      "title": "A captivating, concise, and professional pedagogical title for this QCM",
      "questions": [
        {
          "text": "Question statement?",
          "type": "single", // "single" for single-choice or "multiple" for multiple-choice
          "points": 4, // assign balanced points so the sum of all questions equals EXACTLY 20.
          "options": [
            { "text": "Option A (correct)", "isCorrect": true, "feedback": "Explanation for option A" },
            { "text": "Option B (incorrect)", "isCorrect": false, "feedback": "Explanation for option B" }
          ]
        }
      ]
    }
    
    Absolute Rule: The sum of the "points" for all questions in the "questions" array must be exactly equal to 20.
    ```

---

### 3. "Google Gemini Chat Model" Node (The Brain)
This is the Gemini Pro AI model that writes the questions.
* **How to add it**: Click the small circular connector named **Model*** at the bottom of the *Basic LLM Chain* node, search for **Google Gemini Chat Model**, and add it.
* **Configuration**:
  * **Credential for Google Gemini API**: Click the dropdown menu, select **Create New Credential**, and paste your Google AI Studio API Key (retrieved in Step 1).
  * **Model**: Select `gemini-1.5-pro` from the list.

---

### 4. "Respond to Webhook" Node (Data Return)
This node sends the questions generated by the AI back to Laravel.
* **How to add it**: Click the `+` button, search for **Respond to Webhook**, and connect the output of the **Basic LLM Chain** node to it.
* **Configuration**:
  * **Respond With**: Select `Json Query`.
  * **Response Body**: Paste this exact formula which converts the AI text response into a real JSON array that Laravel can read:
    ```text
    {{ JSON.parse($json.text) }}
    ```

## 🐘 Step 4: Integration inside Laravel Code

You don't need to write complex code. Simply add the following snippets to your files:

### 1. The Route (`routes/web.php`)
Inside your `routes/web.php` file, locate your `formateur` (instructor) route group and add this line:
```php
Route::post('/formateur/qcm/generate-ai', [App\Http\Controllers\FormateurController::class, 'generateWithAI'])->name('formateur.qcm.generate_ai');
```

### 2. The Controller (`FormateurController.php`)
Open `app/Http/Controllers/FormateurController.php` and add this method at the end of the class:
```php
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Http;

public function generateWithAI(Request $request)
{
    // 1. Validate the input from the UI
    $request->validate([
        'topic' => 'required|string|max:255',
        'question_count' => 'required|integer|min:1|max:100',
        'question_type' => 'required|string|in:single,multiple,both',
    ]);

    try {
        // 2. Call the local n8n Webhook
        $response = Http::timeout(120)->post('http://localhost:5678/webhook/generate-qcm', [
            'topic' => $request->input('topic'),
            'question_count' => $request->input('question_count'),
            'question_type' => $request->input('question_type'),
        ]);

        // 3. If n8n responds successfully, return the questions to the frontend
        if ($response->successful()) {
            return response()->json($response->json());
        }

        return response()->json(['error' => 'Error generating questions from the AI.'], 500);
    } catch (\Exception $e) {
        return response()->json(['error' => 'Could not connect to n8n. Make sure n8n is running on port 5678.'], 500);
    }
}
```
